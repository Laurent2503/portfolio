Airlock

Safer coding agents through sandboxing

Coding agents run real shell commands, and when they make a mistake it's already on disk before anyone can review it. Some have deleted databases, and some pass tests by simply editing the tests. In Airlock, every task runs in an isolated sandbox and only the final patch comes out. The patch gets checked by a policy checker, the tests, extra tests written by an agent, and a reviewer agent looking for test tampering. Then a simple controller either commits it or rolls everything back.

  • We're testing it on SWE-bench Pro, SWE-bench Multilingual and Impossible-SWEbench (where the only way to pass is to cheat), plus 40 trap tasks we're writing ourselves and a set of simulated crashes.
  • We're comparing three sandbox types: git worktrees, Docker containers and smolvm microVMs.

Our goal: accept fewer than 10% of cheating patches, reject fewer than 10% of correct ones, and fully restore the previous state after every crash.

ECG Arrhythmia Classification

CNNs vs. Transformers vs. hybrid models

I built and compared different deep learning models to detect irregular heart rhythms from ECG data, using raw waveforms, spectrograms and patient metadata as inputs.

  • Reached 99.0% test accuracy and a 0.93 macro F1 on 4 classes.
  • On raw waveforms, Transformers did much better than CNNs and raised macro F1 from 0.71 to 0.86.
  • The classes were very imbalanced, so a big part of the work was the preprocessing.
